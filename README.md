# Web UI Kit

A curated collection of **60 handcrafted web UI elements** 
HTML, CSS & JS snippets, ready to copy into any project.

No frameworks. No build tools. No dependencies. Just open a file and copy what you need.

## How to Use

1. **Browse** to the category you need
2. **Open** the `.html` file in your browser to preview
3. **Copy** the relevant `<style>` and `<script>` blocks into your project

(If you clone this repo, you can use the "Live Server" Extension in VSC, to get a nice preview of the html files, while editing them to youre needs)
