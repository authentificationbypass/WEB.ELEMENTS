# Cards

10 unique card components — pure HTML, CSS & JS.

| File | Effect | Technique |
|------|--------|-----------|
| [glassmorphism.html](./glassmorphism.html) | Frosted glass look | `backdrop-filter: blur()` |
| [3d-tilt.html](./3d-tilt.html) | 3D tilt following mouse | JS mousemove + rotateX/Y |
| [flip.html](./flip.html) | Flips to reveal back | CSS `perspective` + `rotateY` |
| [expanding.html](./expanding.html) | Expands to show more content | CSS `max-height` transition |
| [neon-border.html](./neon-border.html) | Rotating rainbow border | CSS conic-gradient border |
| [parallax.html](./parallax.html) | Image parallax shift | JS mousemove + `background-position` |
| [gradient-reveal.html](./gradient-reveal.html) | Gradient sweeps to reveal | CSS `clip-path` animation |
| [stack.html](./stack.html) | Stacked cards fan on hover | CSS pseudo-elements + rotate |
| [holographic.html](./holographic.html) | Holographic rainbow sheen | JS mousemove + `mix-blend-mode` |
| [morphing.html](./morphing.html) | Shape morphs on hover | CSS `border-radius` + `clip-path` |
