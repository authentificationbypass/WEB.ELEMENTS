Scroll Progress Bar

How it works

A thin gradient bar at the very top of the viewport expands from left to right as the user scrolls down the page. The percentage reflects how far through the document they've scrolled.

The bar uses a smooth CSS transition for a fluid feel even during fast scrolls, and a glowing box-shadow gives it a premium look without being intrusive.

Implementation

Only a single scroll event listener is needed. We compute scrolled / (scrollHeight - clientHeight) and set it as the width percentage. No libraries required.

Debouncing is not needed here — the width transition on the element absorbs any jitter naturally.

Customization

Change the gradient colors, height, or position to match your brand. You can also replace the width animation with a scaleX transform for GPU compositing, which is more performant on mobile devices.

Adding a background on the bar container (full-width, semi-transparent) gives it a track effect. The percentage label can be toggled on/off or positioned differently.

Accessibility

Add role="progressbar" and aria-valuenow to the bar element and update it dynamically to ensure screen readers can announce the scroll position when needed.
